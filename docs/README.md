# Docs

**PlantUML**

- **Extension:** [PlantUML (jebbs)](https://marketplace.visualstudio.com/items?itemName=jebbs.plantuml)
- **Java:** JRE/JDK on PATH. **Graphviz** (`dot` on PATH) for class diagrams.
- **Preview:** `Alt+D` (or Command Palette → `PlantUML: Preview Current Diagram`)

```bash
java -version && dot -V
```

Optional: **PlantUML: Render** → `PlantUMLServer` if you skip local Java.
